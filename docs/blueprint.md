# **App Name**: EcoCollect

## Core Features:

- Client Dashboard: Client Management Dashboard: Providers can view, filter, and manage clients by collection and payment status.
- Payment Tracking: Payment Tracking & Reporting: Providers access detailed payment histories, balances, and generate reports.
- Collection Map: Interactive Collection Map: A map displays client locations with status indicators. The LLM will act as a tool to decide the display density based on screen size.
- Status Updates: Real-time Status Updates: Providers update collection status for clients/routes (e.g., en route, collected, skipped).
- Client Dashboard: Personalized Dashboard: Clients view service status, payment history, due dates, and collection schedule.
- Status Tracking: Collection Status Tracking: Clients receive real-time updates on their garbage collection status.
- Garbage Reporting: Garbage Status Reporting: Clients use a simple mechanism to indicate if garbage is ready for collection.

## Style Guidelines:

- Primary color: Deep teal (#468499), reminiscent of the earth but more modern than natural greens, for calm and trustworthiness.
- Background color: Very light teal (#F0F8FA), complementing the primary color with a muted, clean background.
- Accent color: Soft gold (#D4AF37), for a professional look that exudes high quality and financial trust.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for headlines or body text
- Use clean, line-based icons with rounded corners for a friendly and modern feel.
- Employ a card-based layout to organize information clearly on both provider and client dashboards.
- Use subtle transitions and animations to provide feedback on user interactions and status updates.
